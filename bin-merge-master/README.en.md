# binMerge

#### Description
在单片机的开发过程中，经常需要将多个单独的bin文件合并成一个文件，方便烧写和生产。这是一个命令行工具，可以实现多个二进制bin文件的合并，任一指定偏移量合并。使用它可以直接将编译好的多个bin文件按照程序员需要合并，而不需费力去重建工程重新编译。有兴趣的朋友可以试试。
